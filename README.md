# TMath 390: Mathematical Statistics with R

Course website built with [Quarto](https://quarto.org/). The `.qmd` sources live in
`src/R/`, and `quarto render` generates the published static site in `site/`.

## Requirements

- [Quarto](https://quarto.org/docs/get-started/) 1.11 or newer
- R 4.3 or newer
- R packages used in the materials: `knitr`, `rmarkdown`, `ggplot2`, `dplyr`, and `plotly`

This machine has Quarto installed at `~/.local/bin/quarto`. Add `~/.local/bin` to your `PATH` if `quarto` is not found.

## Local development

```bash
quarto preview src/R      # live preview
quarto render src/R       # build the site into site/
```

Quarto treats `src/R/` as the project root. The `site/` output directory is
outside the project root, so Quarto may print a path warning during rendering;
the generated site is still correct.

The rendered `site/` directory is committed to the repository. GitHub Pages
serves it directly; no build step runs on GitHub.

## Structure

```text
.
├── assets -> src/R/assets   # convenience symlink
├── src/
│   └── R/                   # Quarto project root
│       ├── _quarto.yml      # site configuration and navigation
│       ├── .nojekyll        # copied to site/.nojekyll
│       ├── index.qmd        # course landing page
│       ├── syllabus.qmd
│       ├── schedule.qmd
│       ├── objectives.qmd
│       ├── assets/          # styles and lecture images
│       ├── lectures/        # Reveal.js lecture sources
│       ├── homework/        # homework sources
│       ├── solutions/       # worked solution sources
│       ├── resources/       # practice and review sources
│       └── tools/           # standalone R scripts
├── site/                    # rendered site published by GitHub Pages
└── docs/                    # private, gitignored course materials
```

`src/R/lectures/`, `homework/`, and `solutions/` contain only `.qmd` files.
Do not edit files in `site/` directly; they are regenerated by `quarto render`.

## Adding datasets

Homework and solutions that read data are currently marked `execute: enabled:
false` so the site can build without the datasets. If the datasets are restored,
place them in `src/R/data/` so the existing `../data/...` paths resolve from the
lecture, homework, and solution folders. Then remove the `execute: enabled:
false` blocks from the affected `.qmd` files.

## Private content

The `docs/` directory is excluded from git and from the site build. It contains:

- `docs/student_data/` — response data and quiz attendance
- `docs/books/` — textbook PDFs
- `docs/quiz_database.docx` — quiz bank with answer keys
- `docs/downloads/` — original DOCX/PDF handouts

Do not move these into `site/`.

## Deployment

The rendered HTML in `site/` is committed and published with GitHub Pages:

1. Run `quarto render src/R`.
2. Commit the updated `site/` directory along with any source changes.
3. Push to GitHub.

The workflow in `.github/workflows/pages.yml` uploads `site/` directly as the
Pages artifact. It does not run Quarto or R; it only publishes the committed
static files. GitHub Pages should be configured with **Build and deployment →
Source → GitHub Actions**.
