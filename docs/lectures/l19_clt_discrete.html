Central Limit Theorem for Discrete RVs

Sampling Distributions for Non-Normal RVs

We learned that if a collection of independent random variables \(X_1, X_2, \dots, X_n\) are normally distributed, then the sample mean is also normally distributed.

What if instead of being normally distributed, we have one of the following scenarios:

  • \(X_i \overset{iid}{\sim} \text{Bernoulli}(p)\)
  • \(X_i \overset{iid}{\sim} \text{Binomial}(n, p)\)
  • \(X_i \overset{iid}{\sim} \text{Poisson}(\lambda)\)
  • \(X_i \overset{iid}{\sim} \text{Geometric}(p)\)

Here \(\overset{iid}{\sim}\) is a shortcut for saying the random variables are independent and identically distributed where identically distributed means they each have the same distribution with the same parameters.

Central Limit Theorem

Theorem 19.1

If \(X_1, X_2, \dots, X_n\) are independent and identically distributed random variables with mean \(\text{E}[X_i] = \mu\) and variance \(\text{Var}[X_i] = \sigma^2 < \infty\), then as \(n \rightarrow \infty\):

\[ \sqrt{n}(\bar{X} - \mu) \overset{D}{\rightarrow} N(0, \sigma) \]

For sufficiently large \(n\) this means that:

\[ \bar{X} \overset{\cdot}{\sim} N\left(\mu, \frac{\sigma}{\sqrt{n}} \right) \]

Here \(\overset{D}{\rightarrow}\) means converges in distribution and \(\overset{\cdot}{\sim}\) means approximately distributed.

Central Limit Theorem and Skew

The more skewed the underlying distribution, the larger a sample size you will need. For Bernoulli/Binomial distributions, the amount of skew is determined by \(p\). If \(p\) is very close to 0 or 1, the distribution will be very skewed.

For Bernoulli/Binomial distributions a good rule of thumb for the CLT to work is:

\[ np \geq 5 \text{ and } n(1-p) \geq 5 \]

For a Geometric distribution, the closer \(p\) is to 0, the better. In contrast, for the Poisson distribution, a larger value of \(\lambda\) will be better.

Ex: Component Failures

Example 19.1

A manufacturer produces electronic components, and each component either passes or fails a quality control test. Suppose the probability that a randomly selected component passes the test is \(p = 0.9\). A random sample of 50 components is selected, and the sample mean \(\bar{X}\), which represents the proportion of passing components, is computed.

According to the Central Limit Theorem, what is the approximate sampling distribution of \(\bar{X}\) (probability of a passing component)?

According to the Central Limit Theorem we have the following:

\[ \begin{align} \bar{X} & \overset{\cdot}{\sim} N\left(p, \sqrt{\frac{p(1-p)}{n}}\right) \\ & \overset{\cdot}{\sim} N\left(0.9, \sqrt{\frac{0.09}{50}}\right) \end{align} \]

Continuity Corrections

Theorem 19.2

Let \(X_1, X_2, \dots, X_n\) be discrete random variables with mean \(\text{E}[X_i] = \mu\) and standard deviation \(\text{SD}[X_i] = \sigma\). Let \(Y\) be a normal random variable with mean \(\mu\) and standard deviation \(\frac{\sigma}{\sqrt{n}}\) (the distribution used to approximate the sampling distribution of \(\bar{X}\)). This means \(Y\) could be used to approximate the distribution of \(\bar{X}\) and \(nY\) could be used to approximate the distribution of \(\sum_{i=1}^n X_i\). Then the following approximations hold:

\[ \begin{align} P(\bar{X} \leq \bar{x}) &\simeq P\left(Y \leq \bar{x} + \frac{0.5}{n}\right) \\ P(\bar{X} < \bar{x}) &\simeq P\left(Y \leq \bar{x} - \frac{0.5}{n}\right) \\ P(\bar{X} \geq \bar{x}) &\simeq P\left(Y \geq \bar{x} - \frac{0.5}{n}\right) = 1- P\left(Y \leq \bar{x} - \frac{0.5}{n}\right)\\ P(\bar{X} > \bar{x}) &\simeq P\left(Y \geq \bar{x} + \frac{0.5}{n}\right) = 1- P\left(Y \leq \bar{x} + \frac{0.5}{n}\right) \\ \end{align} \]

Continuity Corrections (Proof)

Below is a sketch of a proof for the first case:

\[ \begin{align} P(\bar{X} \leq \bar{x}) &= P\left(\frac{1}{n} \sum_{i=1}^n X_i \leq \bar{x} \right) \\ &= P\left(\sum_{i=1}^n X_i \leq n\bar{x} \right) \\ &\simeq P\left(n Y \leq n\bar{x} + 0.5 \right) \\ &= P\left(Y \leq \bar{x} + \frac{0.5}{n} \right) \\ \end{align} \]

Exact Bernoulli Probabilities

Theorem 19.1

If \(X_1, X_2, \dots, X_n\) are independent and identically distributed Bernoulli random variables with success parameter \(p\), then the following is true:

\[ P(\bar{X} \leq \bar{x}) = F_X(n \times \bar{x};n,p) \]

where \(F_X(x;n,p)\) is the CDF for a binomial distribution with parameters \(n\) and \(p\).

\[ \begin{align} P(\bar{X} \leq \bar{x}) &= P\left(\frac{1}{n} \sum_{i=1}^n X_i \leq \bar{x} \right) \\ &= P\left(\sum_{i=1}^n X_i \leq n \times \bar{x} \right) \\ &= F_X(n \times \bar{x};n,p) & \text{Since } \sum_{i=1}^n X_i \sim \text{Binomial}(n, p) \end{align} \]

Exact Binomial Probabilities

Corollary 19.1

If \(X_1, X_2, \dots, X_n\) are independent and identically distributed Binomial random variables with size parameter \(m\) and success parameter \(p\), then the following is true:

\[ P(\bar{X} \leq \bar{x}) = F_X(n \times \bar{x}; n \times m, p) \]

where \(F_X(n \times \bar{x}; n \times m, p)\) is the CDF for a Binomial distribution with size parameter \(n \times m\) and success parameter \(p\). The proof of this is very similar to the previous proof for the Bernoulli case.

Exact Poisson Probabilities

Corollary 19.2

If \(X_1, X_2, \dots, X_n\) are independent and identically distributed Poisson random variables with rate parameter \(\lambda\), then the following is true:

\[ P(\bar{X} \leq \bar{x}) = F_X(n \times \bar{x}; n \times \lambda) \]

where \(F_X(n \times \bar{x}; n \times \lambda)\) is the CDF for the Poisson distribution with rate parameter \(n \times \lambda\).
