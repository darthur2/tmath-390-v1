Expectation and Variance

Expected Value (Expectation)

Definition 11.1

The expected value or population mean of a random variable is one measure of centrality for a variable. It represents the center of mass of the distribution.

For a random variable \(X\), it is denoted by \(\text{E}[X]\) or \(\mu_X\).

For discrete \(X\) this is

\[ \mu_X = \text{E}[X] = \sum_{x\in \mathcal{X}} x \cdot P_X(x) \]

For continuous \(X\) this is

\[ \mu_X = \text{E}[X] = \int_{x\in \mathcal{X}} x \cdot f_X(x) \ dx \]

Ex: Weighted Die

Example 11.1

Consider a four-sided weighted die with weights 0.25, 0.15, 0.35, and 0.25. This is represented by the random variable \(X\) with PMF:

\[ P_X(x) = \begin{cases} 0.25 &\text{ for } x = 1 \\ 0.15 &\text{ for } x = 2 \\ 0.35 &\text{ for } x = 3 \\ 0.25 &\text{ for } x = 4 \\ 0 &\text{ otherwise } \end{cases} \]

What is \(\text{E}[X]\)?

\[ \text{E}[X] = 0.25 \times 1 + 0.15 \times 2 + 0.35 \times 3 + 0.25 \times 4 = 2.6 \]

values <- 1:4
weights <- c(0.25, 0.15, 0.35, 0.25)

sum(values*weights)
[1] 2.6

Ex: Discrete Expectation

Example 11.2

\[ P_X(x) = \begin{cases} \frac{3-x}{6} &\text{for } x = 0, 1, 2, 3 \\ 0 &\text{otherwise} \end{cases} \]

Example 11.4

Let \(X\) be a random variable with PDF:

\[ f_X(x) = \begin{cases} e^{-x} &\text{for } x \in (0, \infty) \\ 0 &\text{otherwise} \end{cases} \]

What is \(\text{E}[X]\)?

\[ \begin{align} \text{E}[X] &= \int_0^\infty x e^{-x} dx \\ &= \left[-x e^{-x}\right]_0^\infty + \int_0^\infty e^{-x} dx &\text{Integration by Parts}\\ &= \lim_{x\rightarrow \infty} -xe^{-x} + \left[-e^{-x}\right]_0^\infty \\ &= \lim_{x \rightarrow \infty} e^{-x} - \lim_{x \rightarrow \infty} e^{-x} + e^{-0} = 1 &\text{ L'Hopitals Rule} \end{align} \]

integrate(function(x) x*exp(-x), lower = 0, upper = Inf)
1 with absolute error < 6.4e-06

Expectation of Functions of Random Variables

Definition 11.2

Let \(X\) be a random variable and let \(g(X)\) be some function of \(X\). The expected value of \(g(X)\), \(\text{E}[g(X)]\) is computed as

\[ \mu_{g(X)} = \text{E}[g(X)] = \sum_{x\in \mathcal{X}} g(x) \cdot P_X(x) \text{ for discrete } X \]

and

\[ \mu_{g(X)} = \text{E}[g(X)] = \int_{x\in \mathcal{X}} g(x) \cdot f_X(x) \ dx \text{ for continuous } X \]

Variance

Definition 11.3

The variance of a random variable \(X\), \(\text{Var}[X]\) is defined as

\[ \sigma^2_X = \text{Var}[X] = \text{E}[(X-\mu)^2] = \sum_{x \in \mathcal{X}} (x-\mu)^2 \cdot P_X(x) \text{ for discrete X} \]

and

\[ \sigma^2_X = \text{Var}[X] = \text{E}[(X-\mu)^2] = \int_{x \in \mathcal{X}} (x-\mu)^2 \cdot f_X(x) \ dx \text{ for continuous X} \]

This expression simplifies to \(\text{E}[g(X)]\) when \(g(X) = (X-\mu)^2\).

Ex: Discrete Variance

Example 11.5

Let the discrete random variable \(X\) have the following PMF:

\[ P_X(x) = \begin{cases} \frac{3-x}{6} &\text{for } x = 0, 1, 2, 3 \\ 0 &\text{otherwise} \end{cases} \]

What is \(\text{Var}[X]\)?

By definition, we have that \(\text{Var}[X]\) is

\[ \text{Var}[X] = \sum_{x=0}^3 \left(x-\frac{2}{3}\right)^2 \cdot \frac{3-x}{6} = \frac{4}{9} \cdot \frac{1}{2} + \frac{1}{9} \cdot \frac{1}{3} + \frac{16}{9} \cdot \frac{1}{6} + \frac{49}{9} \cdot \frac{0}{6} = \frac{5}{9} \]

  (3-x)/6
}

x <- 0:3
sum((x-2/3)^2*PX(x))
[1] 0.5555556

Expectations of Linear Transformations

Theorem 11.1

The expected value of any function of a random variable \(X\) of the form \(g(X) = aX + b\) is:

\[ \text{E}[aX+b] = a\text{E}[X] + b \]

Expectations of Linear Transformations (Proof)

The proof in the continuous case is:

\[ \begin{align} \text{E}[aX + b] &= \int_{x \in \mathcal{X}} (ax+b) \cdot f_X(x) \ dx \\ &= a\int_{x \in \mathcal{X}} x \cdot f_X(x) \ dx + b\int_{x \in \mathcal{X}} f_X(x) \ dx \\ &= a\text{E}[X] + b \end{align} \]

The proof in the discrete case is similar:

\[ \begin{align} \text{E}[aX + b] &= \sum_{x \in \mathcal{X}} (ax+b) \cdot P_X(x) \ dx \\ &= a\sum_{x \in \mathcal{X}} x \cdot P_X(x) \ dx + b\sum_{x \in \mathcal{X}} P_X(x) \ dx \\ &= a\text{E}[X] + b \end{align} \]

Ex: Linear Expectation

Example 11.7

Let the continuous random variable \(X\) have the following PDF:

\[ f_X(x) = \begin{cases} 3 x^2 &\text{for } x \in (0, 1) \\ 0 &\text{otherwise} \end{cases} \]

Let \(g(X) = 3X + 2\). What is \(\text{E}[g(X)] = \text{E}[3X + 2]\)?

\[ \text{E}[3X + 2] = \int_0^1 (3x + 2) \cdot 3x^2 \ dx = \left[\frac{9}{4} x^4 + 2 x^3 \right]_0^1 \simeq 4.25 \]

fX <- function(x){
  3*x^2
}

integrate(function(x) (3*x + 2)*fX(x), lower = 0, upper = 1)
4.25 with absolute error < 4.7e-14

Ex: Linear Expectation, Continued

Example 11.7 (Continued)

Let the continuous random variable \(X\) have the following PDF:

\[ f_X(x) = \begin{cases} 3 x^2 &\text{for } x \in (0, 1) \\ 0 &\text{otherwise} \end{cases} \]

Let \(g(X) = 3X + 2\). What is \(\text{E}[g(X)] = \text{E}[3X + 2]\)?

We know that \(\text{E}[X] = \frac{3}{4}\). From the linearity of expectations, we get that this is:

\[ \text{E}[3X + 2] = 3\text{E}[X] + 2 = 3\frac{3}{4} + 2 = 4.25 \]

Ex: Sales

Example 11.8

Let \(X\) be a random variable representing the number of products sold in a day. Assume we know that \(\text{E}[X] = 4\). Assume that each day you have a base pay of $100, whether you sell products or not. Also assume that you can make another $50 for each product that you sell. How much can you expect to make on any given day?

The amount made in a day is \(g(X) = 50X + 100\). Then we have:

\[ \text{E}[g(X)] = 50\times\text{E}[X] + 100 = 50\times4 + 100 = 300 \]

Variance of Linear Transformations

Theorem 11.2

The variance of any function of a random variable \(X\) of the form \(g(X) = aX + b\) is:

\[ \text{Var}[aX+b] = a^2\text{Var}[X] \]

Variance of Linear Transformations (Proof)

The proof for the continuous case is as follows:

\[ \begin{align} \text{Var}[aX + b] &= \int_{x \in \mathcal{X}} \left((ax+b)-\text{E}[(ax-b)]\right)^2 \cdot f_X(x) \ dx \\ &= \int_{x \in \mathcal{X}} \left(ax-a\mu\right)^2 \cdot f_X(x) \ dx \\ &= a^2\int_{x \in \mathcal{X}} \left(x-\mu\right)^2 \cdot f_X(x) \ dx \\ &= a^2 \text{Var}[X] \end{align} \]

The proof for the discrete case is similar.

Ex: Linear Variance

Example 11.10

Let the continuous random variable \(X\) have the following PDF:

\[ f_X(x) = \begin{cases} 3 x^2 &\text{for } x \in (0, 1) \\ 0 &\text{otherwise} \end{cases} \]

What is \(\text{Var}[3X + 2]\)?

We already know that \(\text{Var}[X] = \frac{3}{80}\). So then the variance of \(3X + 2\) is

\[ \text{Var}[3X+2] = 3^2 \text{Var}[X] = 9 \cdot \frac{3}{80} = \frac{27}{80} \]

Example 11.14

Let the continuous random variable \(X\) have the following PDF:

\[ f_X(x) = \begin{cases} (a+1)(a+2) \ x^a (1-x) &\text{for } x \in (0, 1) \\ 0 &\text{otherwise} \end{cases} \]

Alternative View of Variance

Theorem 11.3

Let \(X\) be a random variable. The variance of \(X\), \(\text{Var}[X]\), can be written as:

\[ \text{Var}[X] = \text{E}[X^2] - \text{E}[X]^2 \]

Alternative View of Variance (Proof)

The proof in the continuous case is as follows:

\[\begin{align} \text{Var}[X] &= E\left[(X - \mu)^2\right] = \int_{x \in \mathcal{X}}(x - \mu)^2 \ f_X(x) \ dx \\ &=\int_{x \in \mathcal{X}} \left(x^2 - 2\mu + \mu^2\right) f_X(x) \ dx \\ &= \int_{x \in \mathcal{X}} x^2 f_X(x) \ dx - 2\mu \int_{x \in \mathcal{X}} x f_X(x) \, dx + \mu^2 \int_{x \in \mathcal{X}} f_X(x) \ dx \\ &= \text{E}[X^2] - 2\text{E}[X] \cdot \text{E}[X] + \text{E}[X]^2 \\ &= \text{E}[X^2] - \text{E}[X]^2 \end{align}\]

The proof in the discrete case is similar.

Example 11.16

Let the continuous random variable \(X\) have the following PDF:

\[ f_X(x) = \begin{cases} 3 x^2 &\text{for } x \in (0, 1) \\ 0 &\text{otherwise} \end{cases} \]

What is \(\text{Var}[X]\)?

We already know that \(\text{E}[X] = \frac{3}{4}\). We find that \(\text{E}[X^2]\) is

\[ \text{E}[X^2] = \int_0^1 x^2 \cdot 3 x^2 \ dx = \left[\frac{3}{5}x^5 \right]_0^1 = \frac{3}{5} \]

Therefore, \(\text{Var}[X]\) is

\[ \text{Var}[X] = \text{E}[X^2] - \text{E}[X]^2 = \frac{3}{5} - \frac{3^2}{4^2} = \frac{3}{80} \]
