Hypothesis Test for Population Mean

Hypothesis Test and Type-I Error

Definition 25.1

A hypothesis test is used to test the plausibility of a null hypothesis about a parameter \(\boldsymbol{\theta}\), \(H_0: \boldsymbol{\theta} \in \Theta_0\), vs an alternative hypothesis, \(H_A: \boldsymbol{\theta} \notin \Theta_0\), using a test statistic \(T(\boldsymbol{X})\). If the distribution of \(T(\boldsymbol{X})\) under the null hypothesis is known, then we can define a rejection region \(R\) such that:

\[P(T(\boldsymbol{X}) \in R | \boldsymbol{\theta} \in \Theta_0) = \alpha\]

where \(\alpha \in (0, 1)\) is the Type-I Error or significance level, the probability of rejecting the null hypothesis when the null hypothesis is true.

P-Value

Definition 25.2

A p-value is the probability of observing a test statistic \(T(\boldsymbol{X})\) as extreme or more extreme than the observed value \(T(\boldsymbol{x})\), given that the null hypothesis is true. The following shows how to calculate p-values for different types of alternative hypotheses:

\[ \begin{align} H_A: \mu \neq \mu_0 &\Rightarrow P\left(T(\boldsymbol{X}) \geq |T(\boldsymbol{x})| \Big| \boldsymbol{\theta} \in \Theta_0 \right) = \text{p} \\ \\ H_A: \mu < \mu_0 &\Rightarrow P\left(T(\boldsymbol{X}) \leq T(\boldsymbol{x}) \Big| \boldsymbol{\theta} \in \Theta_0 \right) = \text{p}\\ \\ H_A: \mu > \mu_0 &\Rightarrow P\left(T(\boldsymbol{X}) \geq T(\boldsymbol{x}) \Big| \boldsymbol{\theta} \in \Theta_0 \right) = \text{p} \end{align} \]

If \(\text{p} < \alpha\), then this implies that \(T(\boldsymbol{x}) \in R\) and we would reject the null hypothesis. In other words, “if \(\text{p}\) is low, reject the null” or “if \(\text{p}\) is low, the null must go”.

Hypothesis Test for Population Mean (Two-Tailed, Known Variance)

Theorem 25.1

Let \(X_1, X_2, \dots, X_n\) be independent and identically distributed normal random variables with unknown mean \(\mu\) and known standard deviation \(\sigma\). Assume we want to test the hypothesis \(H_0: \mu = \mu_0\) vs \(H_A: \mu \neq \mu_0\) and we want the Type-I error rate to be no larger than \(\alpha\). Then we would reject \(H_0\) when the following was true:

\[ \frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}} < z_{\alpha/2} \quad \text{ or } \quad \frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}} > z_{1-\alpha/2} \]

More succinctly, we can reject \(H_0\) when \(\left|\frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}} \right| > z_{1-\alpha/2}\)

If the underlying distribution is unknown, we can still apply this if \(n \geq 30\).

Hypothesis Test for Population Mean (Two-Tailed, Known Variance, Proof)

Under the null hypothesis, \(X_1, X_2, \dots, X_n\) are distributed normally with mean \(\mu = \mu_0\) and standard deviation \(\sigma\). Then \(\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0, 1)\). Thus, if the null hypothesis is true, the probability of rejecting the null using this rejection region is:

\[ P\left(\frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}} < z_{\alpha/2}\right) + P\left(\frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}} > z_{1-\alpha/2}\right) = P\left(\left|\frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}} \right| > z_{1-\alpha/2}\right) = \alpha \]

If the underlying distribution is unknown, we can still apply this if \(n \geq 30\).

Hypothesis Test for Population Mean (Left-Tailed, Known Variance)

Theorem 25.2

Let \(X_1, X_2, \dots, X_n\) be independent and identically distributed normal random variables with unknown mean \(\mu\) and known standard deviation \(\sigma\). Assume we want to test the hypothesis \(H_0: \mu = \mu_0\) vs \(H_A: \mu < \mu_0\) and we want the Type-I error rate to be no larger than \(\alpha\). Then we would reject \(H_0\) when the following was true:

\[ \frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}} < z_{\alpha} \]

Again, under the null hypothesis, we have that \(\frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}} \sim N(0, 1)\). Thus, if the null is true, the probability of rejecting it would be:

\[ P\left(\frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}} < z_{\alpha}\right) = \alpha \]

If the underlying distribution is unknown, we can still apply this if \(n \geq 30\).

Hypothesis Test for Population Mean (Right-Tailed, Known Variance)

Theorem 25.3

Let \(X_1, X_2, \dots, X_n\) be independent and identically distributed normal random variables with unknown mean \(\mu\) and known standard deviation \(\sigma\). Assume we want to test the hypothesis \(H_0: \mu = \mu_0\) vs \(H_A: \mu > \mu_0\) and we want the Type-I error rate to be no larger than \(\alpha\). If the underlying distribution is unknown, we can still apply this if \(n \geq 30\).

P-Value for Population Mean (Two-Tailed, Known Variance)

For a two-tailed test involving the population mean with known variance (\(H_A: \mu \neq \mu_0\)), the p-value would be computed as follows:

\[ P\left(\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \geq \left|\frac{\bar{x}-\mu}{\sigma/\sqrt{n}} \right| \Bigg| \mu = \mu_0\right) \]

In words, this is literally the probability of getting a test-statistic as larger or larger than what we observed, assuming the null hypothesis is true.

P-Value for Population Mean (Left-Tailed, Known Variance)

For a left-tailed test involving the population mean with known variance (\(H_A: \mu < \mu_0\)), the p-value would be computed as follows:

\[ P\left(\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \leq \frac{\bar{x}-\mu}{\sigma/\sqrt{n}} \Bigg| \mu = \mu_0\right) \]

P-Value for Population Mean (Right-Tailed, Known Variance)

For a right-tailed test involving the population mean with known variance. (\(H_A: \mu > \mu_0\)), the p-value would be computed as follows:

\[ P\left(\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \geq \frac{\bar{x}-\mu}{\sigma/\sqrt{n}} \Bigg| \mu = \mu_0\right) \]

Hypothesis Test for Population Mean (Two-Tailed, Unknown Variance)

Theorem 25.4

Let \(X_1, X_2, \dots, X_n\) be independent and identically distributed normal random variables with unknown mean \(\mu\) and unknown standard deviation \(\sigma\). Assume we want to test the hypothesis \(H_0: \mu = \mu_0\) vs \(H_A: \mu \neq \mu_0\) and we want the Type-I error rate to be no larger than \(\alpha\). Then we would reject \(H_0\) when the following was true:

\[ \frac{\bar{x}-\mu_0}{s/\sqrt{n}} < t_{n-1, \alpha/2} \quad \text{ or } \quad \frac{\bar{x}-\mu_0}{s/\sqrt{n}} > t_{n-1, 1-\alpha/2} \]

More succinctly, we can reject \(H_0\) when \(\left|\frac{\bar{x}-\mu_0}{s/\sqrt{n}} \right| > t_{n-1, 1-\alpha/2}\)

The proofs for this are very similar to the case when the standard deviation is known. If the underlying distribution is unknown, we can still apply this if \(n \geq 30\).

Ex: Batteries (1)

Example 25.1

Historically, the average weight for a certain type of battery has been 51 grams, but it believed that the weight has increased. A random sample of 40 batteries is selected, and their average weight is found to be 51.5 grams. It is known that the weight of these batteries follows a normal distribution with a standard deviation of 1.8 grams.

Assume a significance level of \(\alpha = 0.05\). What test-statistic would we use for this test and what critical value is used to define the rejection region?

  • \(H_0: \mu = 51\)
  • \(H_A: \mu > 51\)

This test would use a z-statistic since \(\sigma\) is known

alpha <- 0.05

cat("The critical value is: ", qnorm(1-alpha))
The critical value is:  1.644854

Ex: Batteries (2)

Example 25.4

Historically, the average weight for a certain type of battery has been 51 grams, but it is believed that the weight has increased. A random sample of 40 batteries is selected, and their average weight is found to be 51.5 grams. It is known that the weight of these batteries follows a normal distribution with a standard deviation of 1.8 grams.

Using a significance level of \(\alpha = 0.05\), test the hypothesis that the true average weight has increased from 51 grams.

  • \(H_0: \mu = 51\)
  • \(H_A: \mu > 51\)
n <- 40
sigma <- 1.8
mu_0 <- 51
xbar <- 51.5
alpha <- 0.05
z_statistic <- (xbar-mu_0)/(sigma/sqrt(n))

cat("The z-statistic is: ", z_statistic, ", the critical value is: ", qnorm(1-alpha), ", and the p-value is: ", 1-pnorm(z_statistic), sep = "")
The z-statistic is: 1.756821, the critical value is: 1.644854, and the p-value is: 0.03947417

Given a set of observations with unknown mean and unknown standard deviation, we can use the t.test function in R to perform a hypothesis test for the population mean.

Example 25.10

A researcher is studying the effects of a new fertilizer on plant growth. They believe that before using this fertilizer that the average growth was 22 centimeters. However, they believe that it is greater now that they are using this new fertilizer. They measure the height (in cm) of 10 randomly selected plants after four weeks of growth:

growth <- c(22.4, 21.8, 23.1, 24.0, 22.7, 23.5, 21.9, 22.6, 23.3, 22.1)

The researcher assumes that plant heights follow a normal distribution. Using a significance level of \(\alpha = 0.05\), perform a hypothesis test to test the hypothesis that the average growth has increased.

n <- length(growth)
t_statistic <- (mean(growth)-22)/(sd(growth)/sqrt(n))

cat("The t-statistic is: ", t_statistic, ", the critical value is: ", qt(1-0.05, n-1), ", and the p-value is: ", 1-pt(t_statistic, n-1), sep = "")
The t-statistic is: 3.223151, the critical value is: 1.833113, and the p-value is: 0.005218276
