Simple Linear Regression

Correlation

Definition 29.1

Let \(X\) and \(Y\) be two random variables. The correlation between \(X\) and \(Y\) measures the strength and direction of a linear relationship between \(X\) and \(Y\) and is defined as:

\[ \rho = \frac{\sigma_{XY}}{\sigma_X \sigma_Y} \] where \(\sigma_{XY} = \text{Cov}(X, Y)\), and \(\sigma_X\) and \(\sigma_Y\) are the standard deviations for \(X\) and \(Y\) respectively.

We have that \(-1 \leq \rho \leq 1\) where \(\rho = 1\) indicates a strong positive linear relationship between \(X\) and \(Y\) and \(\rho = -1\) indicates a strong negative linear relationship.

The closer that \(\rho\) is to \(0\), the weaker the relationship.

Estimate of Correlation

Definition 29.2

Let \(x_1, x_2, \dots, x_n\) be \(n\) realizations of the random variable \(X\) and let \(y_1, y_2, \dots, y_n\) be \(n\) realizations of the random variable \(Y\). An estimate of the correlation coefficient \(\rho\) is obtained as:

\[ r = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^n (y_i - \bar{y})^2}} \]

Simple Linear Regression

Definition 29.3

A simple linear regression model is a model that relates a predictor or independent variable \(X\) to a response or dependent variable \(Y\) using a linear model. Let \(x_1, x_2, \dots, x_n\) be realizations of \(X\) and let \(y_1, y_2, \dots, y_n\) be realizations of \(Y\). Then the simple linear regression model relating \(X\) to \(Y\) is:

\[ y_i = \beta_0 + \beta_1 x_i + \varepsilon_i \]

Here \(\beta_0\), the intercept represents the expected value of \(Y\) when \(X = 0\). The slope coefficient \(\beta_1\) represents the expected increased in \(Y\) for a unit increase in \(X\). The error \(\varepsilon\) represents the difference between the true value of \(Y\) and the predicted value of \(Y\), given by \(\beta_0 + \beta_1 X\).

Moving forward, we assume that \(\text{E}[\varepsilon_i] = 0\) and \(\text{Var}[\varepsilon_i] = \sigma^2 < \infty\), implying that \(\text{E}[y_i|x_i] = \beta_0 + \beta_1x_i\) and \(\text{Var}[y_i|x_i] = \sigma^2\).

Least Squares Estimates of \(\beta_0\) and \(\beta_1\)

Definition 29.4

The least squares estimates of \(\beta_0\) and \(\beta_1\) in the SLR model are those values of \(\beta_0\) and \(\beta_1\) that minimize the mean square error (MSE):

\[ \frac{1}{n} \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2 \]

In other words, the least squares estimates are the solutions to the following optimization problem:

\[ \hat{\beta}_0, \hat{\beta}_1 = \underset{\beta_0, \beta_1}{\text{argmin}} \left[ \frac{1}{n} \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2 \right] \]

Least Squares Estimates of \(\beta_0\) and \(\beta_1\)

Theorem 29.1

If \(\text{E}[\varepsilon_i] = 0\), then the least squares estimates of \(\beta_0\) and \(\beta_1\) in the SLR model are:

\[ \begin{align} b_1 &= \hat{\beta}_1 = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} = \frac{s_{XY}}{s_X^2} = \frac{s_Y}{s_X} r\\ b_0 &= \hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x} \end{align} \]

Least Squares Estimate of \(\beta_0\) (Proof)

\[ \begin{align} &\frac{\partial}{\partial \beta_0} \frac{1}{n} \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2 = 0 \\ &\implies -\frac{2}{n} \sum_{i=1}^n (y_i - \beta_0 - \beta_1x_i) = 0 \\ &\implies \sum_{i=1}^n y_i - n \beta_0 - \beta_1 \sum_{i=1}^n x_i = 0 \\ &\implies n\beta_0 = \sum_{i=1}^n y_i - \beta_1\sum_{i=1}^n x_i \\ &\implies \hat{\beta}_0 = \bar{y} - \beta_1\bar{x} \end{align} \]

Least Squares Estimate of \(\beta_1\) (Proof)

\[ \begin{align} &\frac{\partial}{\partial \beta_1} \frac{1}{n} \sum_{i=1}^n (y_i - (\bar{y} - \beta_1\bar{x} + \beta_1 x_i))^2 = 0 \\ &\frac{\partial}{\partial \beta_1} \frac{1}{n} \sum_{i=1}^n (y_i - \bar{y} + \beta_1 \bar{x} - \beta_1x_i)^2 = 0 \\ &\frac{\partial}{\partial \beta_1} \frac{1}{n} \sum_{i=1}^n (y_i - \bar{y} - \beta_1(x_i - \bar{x}))^2 = 0 \\ &\implies -\frac{2}{n}\sum_{i=1}^n\left[(y_i - \bar{y}) - \beta_1(x_i - \bar{x})\right] (x_i -\bar{x}) = 0 \\ &\implies \sum_{i=1}^n \left[(y_i-\bar{y})(x_i-\bar{x}) - \beta_1 (x_i-\bar{x})^2\right] = 0 \\ &\implies \hat{\beta}_1 = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} \end{align} \]

SLR Predictions and Residuals

Definition 29.5

The predicted value \(\hat{y}_i\) for a given value of \(x_i\) is obtained using the following equation:

\[ \hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1 x_i \]

where \(\hat{\beta}_0\) and \(\hat{\beta}_1\) are the least squares estimates of \(\beta_0\) and \(\beta_1\).

The residual for observation \(y_i\) is defined as:

\[ e_i = \hat{\varepsilon}_i = y_i - \hat{y}_i \]

Distributions for \(\hat{\beta}_0\) and \(\hat{\beta}_1\)

Theorem 29.2

Assume that \(\varepsilon_i \overset{iid}{\sim} N(0, \sigma)\). Then \(y_i \overset{iid}{\sim} ~ N(\beta_0 + \beta_1 x_i, \sigma)\) and it can be shown that:

\[ \begin{align} \frac{\hat{\beta}_0-\beta_0}{s\sqrt{\left(\frac{1}{n} + \frac{\bar{x}^2}{\sum_{i=1}^n (x_i - \bar{x})^2}\right)}} &\sim t_{n-2} \\ \frac{\hat{\beta}_1-\beta_1}{\frac{s}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2}}} &\sim t_{n-2} \end{align} \]

where \(s = \sqrt{\frac{1}{n-2} \sum_{i=1}^n (y_i - \hat{y}_i)^2}\) is the residual standard error. The terms \(s\sqrt{\left(\frac{1}{n} + \frac{\bar{x}^2}{\sum_{i=1}^n (x_i - \bar{x})^2}\right)}\) and \(\frac{s}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2}}\) are the standard errors for \(\hat{\beta}_0\) and \(\hat{\beta}_1\) respectively.

Hypothesis Tests for \(\beta_0\) and \(\beta_1\)

Theorem 29.3

Let \(y_i \overset{iid}{\sim} N(\beta_0 + \beta_1 x_i, \sigma)\) and let \(\hat{\beta}_0\) and \(\hat{\beta}_1\) be the least squares estimates of \(\beta_0\) and \(\beta_1\). Then the test that rejects the null hypothesis \(H_0: \beta_1 = 0\) in favor of \(H_A: \beta_1 \neq 0\) if:

\[ \left|\frac{\hat{\beta}_1}{\frac{s}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2}}}\right| \geq t_{1-\alpha/2,n-2} \] has significance level \(\alpha\). Likewise, the test that rejects \(H_0: \beta_0 = 0\) in favor of \(H_A: \beta_0 \neq 0\) if:

\[ \left|\frac{\hat{\beta}_0}{s\sqrt{\left(\frac{1}{n} + \frac{\bar{x}^2}{\sum_{i=1}^n (x_i - \bar{x})^2}\right)}}\right| \geq t_{1-\alpha/2, n-2} \] has significance level \(\alpha\).

Confidence Intervals for \(\beta_0\) and \(\beta_1\)

Theorem 29.4

Let \(y_i \overset{iid}{\sim} N(\beta_0 + \beta_1 x_i, \sigma)\) and let \(\hat{\beta}_0\) and \(\hat{\beta}_1\) be the least squares estimates of \(\beta_0\) and \(\beta_1\). Then the following interval for \(\beta_1\):

\[ \hat{\beta}_1 \pm t_{1-\alpha/2,n-2} \times \frac{s}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2}} \] is a confidence interval with confidence level \(1-\alpha\). Likewise, the following interval for \(\beta_0\):

\[ \hat{\beta}_0 \pm t_{1-\alpha/2, n-2} \times s\sqrt{\left(\frac{1}{n} + \frac{\bar{x}^2}{\sum_{i=1}^n (x_i - \bar{x})^2}\right)} \] is a confidence interval with confidence level \(1-\alpha\).

n <- nrow(study_hours)

Example 26.7

You are interested in understanding the relationship between the size of a house in square feet \(X\) and the price of the house in thousands of dollars \(Y\). You collect a random sample of 50 homes in your area. Construct a 95% prediction interval for a new response at \(x_h = 2700\).

n <- nrow(housing)
xh <- 2700
y_hat <- b0_house + b1_house*xh

alpha <- 0.05
t_quant <- qt(1-alpha/2, n-2)
s_house <- sqrt(1/(n-2)*sum(house_resids^2))
mr_se_house <- s_house*sqrt(1 + 1/n + (xh-mean(sqft))^2/sum((sqft-mean(sqft))^2))

y_hat + c(-1,1)*t_quant*mr_se_house
