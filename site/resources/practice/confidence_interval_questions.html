Question 1

A software engineering company is interested in comparing the performance of two different programming languages, Python and Java, in terms of their average execution time for a specific task. The company runs an experiment in which a random sample of 30 Python scripts and 35 Java scripts are executed, and the execution times (in seconds) for each script are recorded.
