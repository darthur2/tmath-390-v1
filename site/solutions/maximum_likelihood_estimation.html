Maximum Likelihood Estimation

Question 1A (2 points)

Let \(X_1, X_2, \dots X_n\) be normally distributed random variables with mean \(\mu\) and standard deviation \(\sigma\). Complete the function normal_joint_pdf below that takes as input a vector of observed values \(\boldsymbol{x}\), a mean \(\mu\), and a standard deviation \(\sigma\) and computes the joint density of \(\boldsymbol{x}\), \(f_\boldsymbol{X}(x_1, x_2, \dots, x_n; \mu, \sigma)\).

normal_joint_pdf <- function(x, mu, sigma){
  # x: Vector of observed values
  # mu: mean
  # sigma: standard deviation
  
  prod(dnorm(x, mu, sigma))
  
  # n <- length(x)
  # (2*pi*sigma^2)^(-n/2)*exp(-1/(2*sigma^2)*sum((x-mu)^2))
}

Note: You may use the dnorm function or you may write out the joint density.

Question 2A (2 points)

Let \(X_1, X_2, \dots, X_n\) be beta random variables with unknown shape parameter and known shape parameter \(\beta = 3\). In this case the likelihood function for \(\alpha\) would be:

\[ \left(\frac{\Gamma(\alpha+3)}{\Gamma(\alpha)\Gamma(3)} \right)^n \prod_{i=1}^n x_i^{\alpha-1} \prod_{i=1}^n (1-x_i)^2 \]

Complete the function log_lik_beta below that computes the log-likelihood for \(\alpha\) for a given set of observed values \(x\). It should takes as input a vector of observations \(x\) and a value for \(\alpha\) and computes the log-likelihood of \(\alpha\) given that set of observations.

log_lik_beta <- function(x, alpha){
  # x: Vector of observations
  # alpha: Value of shape parameter
  
  n <- length(x)
  
  n*log(gamma(alpha + 3)) - n*log(gamma(alpha)) - n*log(gamma(3)) +
    (alpha-1)*sum(log(x)) + 2*sum(log(1-x))
  
  # n*lgamma(alpha + 3) - n*lgamma(alpha) - n*lgamma(3) +
  #   (alpha-1)*sum(log(x)) + 2*sum(log(1-x))
}

Note: If you’d like you may use the function lgamma to compute the log of the gamma function \(\log(\Gamma(x))\).

Question 3 (4 points)

Let \(X\) be a continuous random variable with the following PDF:

\[ f_X(x; a) = \begin{cases} \frac{3 x^2}{a^3} & \text{for } x \in [0, a] \\ 0 & \text{otherwise} \end{cases} \]

where \(a\) is a parameter governing the upper bound for \(X\). This can also be written more compactly using an indicator function:

\[ f_X(x; a) = \frac{3 x^2}{a^3} \ 1[0 \leq x \leq a] \]

The likelihood function for \(a\) is:

\[ L(a;\boldsymbol{x}) = \frac{3}{a^3} \prod_{i=1}^n x_i^2 \ \prod_{i=1}^n 1[0 \leq x_i \leq a] \]

Find the maximum likelihood estimator for \(a\).

Hint: Trying to use calculus to find where the derivative of the likelihood (or log-likelihood) is 0 is not going to work well here. First, consider what would have to happen for \(\prod_{i=1}^n 1[0 < x_i < a]\) to be \(1\) (i.e., what has to be true of all \(x_i\)?). Then, ask yourself for which value of \(a\) will the likelihood (or log-likelihood) function be largest.

The maximum \(x_{(n)}\) is the maximum-likelihood estimator of \(a\).

Question 4 (3 points)

Consider the likelihood function presented in the previous problem (Part 2 Question 5). In the code block below, complete the function log_lik_a so that it takes as input a value of \(a\) and returns the log-likelihood function for \(a\) given a vector of observations \(\boldsymbol{x}\), which are provided for you.

Then use this function with the optimize function to find the maximum-likelihood estimate. Do the results match the closed-form solution from the previous question?

Note: If a function references a variable that isn’t given as input, it will look in the global environment for the variable. In this instance, we use x14 in the function log_lik_a. Even though we don’t give this as input, it will find it since we created it beforehand. In general, this isn’t good practice, but simplifies things for this question.

Another Note: You might get some warnings using the optimize function. As long as you get an answer that makes sense, you can ignore the warnings.

x14 <- c(3.09, 3.79, 1.93, 1.98, 4.37, 3.92, 4.85, 4.74, 4.62, 4.66)

log_lik_a <- function(a){
  # a: Upper bound parameter
  
  xn <- max(x14)
  log(3) - 3*log(a) - 2*sum(log(x14)) + log(ifelse(xn >= 0 & xn <= a, 1, 0))
}

suppressWarnings(optimize(log_lik_a, interval = c(1, 10), 
                          maximum = TRUE)$maximum)
[1] 4.850017

This numerical estimate is very close to the maximum, which we found was the closed-form maximum likelihood estimator.
